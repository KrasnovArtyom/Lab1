# Лабораторная работа №1: Поиск общих элементов в отсортированных массивах

## Реализованные алгоритмы
1. Два указателя (algo1) — O(N+M), память O(1). Идеален для массивов сопоставимого размера.
2. Бинарный поиск (algo2) — O(N log M), память O(1). Классический поиск для каждого элемента.
3. Экспоненциальный поиск (algo3) — O(N log M), память O(1). Использует галопирующий шаг от предыдущей позиции (prev_try).
4. Двойной бинарный поиск (algo4) — O(N log M), память O(log N). Стратегия «разделяй и властвуй».

## Структура проекта
* src/ — исходный код на C++ (алгоритмы, тесты, бенчмарки)
* data/ — сырые данные (CSV) с результатами замеров
* docs/ — отчет в формате Word и Excel-файл с графиками

## Инструкция по запуску
1. Откройте файл решения LaboratoryWork.sln в Visual Studio.
2. В файле src/main.cpp выберите нужную функцию для запуска:
   * correctness_test() — ручные краевые тесты (84 проверки).
   * random_test() — 5000 случайных массивов (сравнение с брутфорсом).
   * bench_test1(), bench_diagonal(), bench_evil() — бенчмарки для сбора статистики.
3. Соберите проект и запустите.
